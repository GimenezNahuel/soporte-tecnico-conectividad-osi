# Network Connectivity Troubleshooting Based on the OSI Model

This repository documents a structured troubleshooting methodology (*Bottom-Up* approach) for network and telecommunications incident resolution, applying the OSI model as a technical standard for fault isolation and diagnosis.

## Repository Structure

* **[OSI Diagnostic Guide](docs/OSI-Guide.en.md):** Standard Operating Procedure (SOP) for methodical layer-by-layer verification (Layer 1 to Layer 7).
* **Case Studies (Real-World Incidents):**
  * **[Case #NET-01 (Core Router & WAN Outage)](cases/case-01-core-router.en.md):** Resolution of a critical corporate-wide outage through network and transport layer isolation.
  * **[Case #NET-02 (Wi-Fi Drops / ISP Degradation)](cases/case-02-wifi-drops.en.md):** Differential diagnosis ruling out local network failures versus external transport link issues.
  * **[Case #NET-03 (VPN Troubleshooting & DNS Cache)](cases/case-03-vpn-dns.en.md):** Resolving name resolution failures and re-establishing remote tunnels at upper layers.
